Mystery
Pieces are selected by binary flag. Try 1.
Piece Type
Selects which type of pieces to use: pieces selected by binary, polyomino sizes selected by binary, random-walk shapes, or all shapes
Next Pieces
The number of upcoming pieces you get to see.
Held Pieces
The number of pieces you get to hold.
Sticky Percentage
Each piece has this percentage chance to be Sticky, which means it'll land upon trying any invalid move.
Ghosty Percentage
Each piece has this percentage chance to be Ghosty. Each cell of a Ghosty piece may enter and exit solid locations.
Morph Percentage
Every time a piece reappears, it has this percentage chance to have one cell added or removed.
Flips
When this is on, you may mirror-reverse a piece by pressing E.
Garbage Rows
The number of rows at the bottom of the grid whose cells will have a chance to spawn already full.
Garbage Percentage
The percentage of cells that will spawn already full.
Replenishing Garbage
This decides whether or not a new garbage row appears when a line of garbage is cleared.
Board Width
The number of columns that the board has.
Board Height
The number of rows that the board has.
Wrap Around
This decides whether the left wall connects to the right wall or just behaves as a wall.
Stairs Mode
In stairs mode, the floor is shaped like stairs instead of being flat. This does also mean that stair-shaped lines clear instead of horizontal lines.
Deadly Floor
When this setting is enabled, tetrominos colliding with the floor causes an automatic loss.
Hexagon Mode
Normally the grid is made of squares. In Hexagon Mode, the grid is made of hexagons instead.
Falling Delay
This is the number of frames it takes for a piece to fall.
Falling Acceleration
This is the amount that the falling delay is divided by every time you gain a point.
Score Acceleration
Clearing no lines scores 0 points, clearing one line scores 1 point. This is how many more points each additional line is worth.
Allowed Holes
This is how many holes are allowed before the game decides that a line will not be cleared.
Behavior on Loss
This decides what happens when you lose the game: Nothing, the game restarts, or all non-UI settings other than this one get reshuffled.
Fill Small Holes
If this is on, after a piece lands, any empty space that is only adjacent to full spaces will be filled as well.
Social Distancing
If this is on, after a piece lands, any empty space that is adjacent to at least one full space will be filled as well.
Dual Mode
In Dual Mode, the board generates half-full, and every other piece consists of empty spaces going upward instead.
Diagonal Adjacencies
This decides if cells that touch only at a corner are considered adjacent or not.
Dual Inverts Left-Right
This decides if the left and right arrows move the piece in the opposite direction when said piece is inverted.
Dual Inverts Up-Down
When this is on, the up controls move inverted pieces up rather than still rotating.
Dual Inverts Rotation
This decides if rotation of inverted pieces is clockwise or counterclockwise.
Wrap Around Display Change
Normally, when Wrap Around is on, the camera moves to follow the piece. When this setting is on, the camera will instead show two copies of the playfield.
Piece Randomization Difficulty Bias
This decides how biased the Shuffle button is toward difficult pieces.
Piece Randomization Same Color Bias
This decides how biased the Shuffle button is toward pieces of similar color.
Piece Randomization Symmetry Bias
This decides how biased the Shuffle button is toward symmetric pieces.
Piece Color Red Channel Mode
There are five implemented methods of assigning brightness to a piece, this setting decides which one is used for the red channel.
Piece Color Green Channel Mode
This decides which piece-coloring method is used for the green channel of a piece.
Piece Color Blue Channel Mode
This decides which piece-coloring method is used for the blue channel of a piece.
Use Static Color
When this is on, it overrides the above described procedure and just uses hand-assigned colors for pieces that have them. (Except that doesn't currently work right now.)
